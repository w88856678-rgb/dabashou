# 搭把手｜蛇口小店资源互助板

用供需便签、资源匹配和模拟协商，体验邻里小店如何借人手、借设备、共享空间与物料。

[打开交互体验版](https://w88856678-rgb.github.io/dabashou/)

## 适合谁

- 小店经营者：体验把临时需求说清楚、寻找邻店资源的流程。
- 社区与街区运营者：讨论小店互助中的供需表达、组队与沟通方式。
- 公益及产品策划者：观察资源互助原型，梳理真实服务还需要哪些条件。

## 可以做什么

- **发布供需便签**：填写需求或可提供的资源、类别和可用时间。
- **探索资源匹配**：查看模拟邻店候选，在单店方案和组队方案之间切换。
- **体验协商过程**：发起模拟邀请，在对话中沟通时间与资源细节。
- **管理便签和收藏**：完成、恢复或删除自己的便签，把候选保存到“稍后再看”。
- **查看互助守则**：围绕先沟通、说清楚、按时归还等原则讨论互助流程。

## 如何使用

1. 打开资源板，浏览示例便签，或发布一张自己的需求 / 资源便签。
2. 进入匹配页面，比较单店与组队方案，查看候选说明。
3. 发起模拟邀请并体验对话；之后可在“我的便签”和“稍后再看”中管理记录。

## 体验与数据边界

这是交互体验版：店铺资源、对方响应和履约均为模拟，不联系真实店主，也不代表已达成真实互助。

便签、对话等体验记录保存在当前浏览器。云端 AI 启用后，当前需求、候选资料或最近 8 条对话会发送给 DeepSeek 处理，用于生成组队建议和模拟回复；AI 未启用或不可用时使用本地规则。
